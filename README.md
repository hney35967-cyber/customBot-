# 🤖 CustomBot

CustomBot is an AI Customer Support Assistant built with
Python and Streamlit.

## ✨ Features

- 📚 RAG-style document search
- 💬 Conversation memory
- 👩‍💼 Human support escalation
- 🖥️ Streamlit chat interface
- 🚀 Ready for GitHub and Streamlit Community Cloud
